# 网盘直连播放

视频播放只允许直连。收藏、分享和已缓存资源共用这一规则：站内接口验证账号和播放会话后返回302，浏览器直接读取网盘视频。应用服务器不转发视频、HLS清单或分片。

- MP4等渐进式源使用原生媒体请求，不设置 `crossorigin`。设备必须支持文件的音视频编码。
- HLS只提供给 `canPlayType('application/vnd.apple.mpegurl')` 支持原生HLS的客户端，清单和分片由系统媒体管线直接加载。网盘HLS未提供浏览器CORS授权时，不使用服务器代理补足。
- 非原生HLS客户端优先使用渐进式直连；只有HLS时可使用账号允许的原文件下载直链。没有可用直连画质会明确失败，可选择其他片源或浏览器。
- TV认证失败或上游不可用时不切换Cookie视频代理。Cookie仍用于片库管理、资源转存和同目录字幕读取。
- 旧 `PLAYER_MEDIA_DELIVERY=proxy` 配置不再生效；`delivery=proxy` 和旧媒体分片代理接口会返回禁用错误。

TV访问令牌被上游拒绝时，会合并并发刷新并重试一次。刷新失败不会把长期刷新凭据直接删除；没有有效认证时，由管理员重新认证。TV认证交换继续使用部署配置的 `TV_TOKEN_EXCHANGE_URL`（默认 `https://api.extscreen.com/quarkdrive/token`）。

字幕、海报、缩略图、API和元数据仍使用应用服务。MP4内嵌字幕提取只按原有限额读取索引和字幕范围；这不等于转发整段播放视频。

“画质”按钮只显示清晰度选项。控制栏的画面键循环切换完整适应、按窗口铺满、125%放大裁切。网页播放区保持16:9；切换不重新加载视频或重置时间。iPhone原生全屏由系统播放器决定缩放，网页CSS不改变原生全屏画面。

验证应覆盖登录/会话所有者、GET和HEAD只重定向且响应无媒体正文、旧代理参数和分片接口拒绝、失效认证不降级、访问令牌刷新并发，以及原生HLS能力过滤。真实设备的解码能力与系统全屏仍需在对应设备验收。

## 认证与升级

1. 管理员进入“设置 → 高级配置”，配置网盘网页 Cookie，用于片库、转存及字幕读取。
2. 完成 TV 播放认证后再播放视频。默认认证交换服务会接收授权码和刷新令牌；可通过 `TV_TOKEN_EXCHANGE_URL` 指向兼容的 HTTPS 服务。令牌加密保存在当前部署的数据目录中。
3. 升级无需清空数据卷。仅配置 Cookie 的旧部署需要补充 TV 认证；旧的代理模式不会继续生效。
4. 页面及反向代理保留 `Referrer-Policy: no-referrer`，避免网盘拒绝携带站点 Referer 的媒体请求。
